# NOTICODE

> The Autonomous Software Engineering Platform

---

## Vision

Build the world's most capable autonomous software engineering platform.

Noticode is not just another AI assistant.

It is an autonomous software engineer capable of understanding, reasoning, planning, executing, testing and improving software projects.

---

## Core Principles

- Understand before acting.
- Plan before coding.
- Verify before committing.
- Learn from every execution.
- Security by design.
- Human remains in control.

---

## Architecture

Noticode is composed of several independent modules.

- Core
- Planner
- Memory
- Tool Engine
- Indexer
- Models
- API
- Desktop
- CLI
